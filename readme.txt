== Description ==
See how long people really read each post. Measures active reading time and scroll depth, compares it with the estimated reading time, and adds a Reading time column to your posts list. No cookies, no IP storage, no external services.

Created by Dulal Das: https://www.facebook.com/share/1CJkZsQtna/

* No cookies, no IP addresses stored, no external requests, no ads.
* All assets are bundled with the plugin.

== Installation ==
1. Upload the folder to /wp-content/plugins/ and activate.
2. Open Tools > Engagement Time.
